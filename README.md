# DCS: Diversity-Constrained Density-Ratio Selection for Test-Time Context Optimization of Tabular Foundation Models under Distribution Shift

This repository contains the complete source code to reproduce all experiments in the paper. Every number reported in the manuscript (Tables 3–22, Figures 2–5) is generated by the scripts below.

## Requirements

- Python 3.10+ (developed and tested on 3.13)
- NVIDIA GPU with ≥ 12 GB VRAM (for local TabPFN inference; developed on RTX Pro 2000 16 GB)
- ~30 GB disk space (datasets + TabPFN model weights)

```bash
pip install -r requirements.txt
```

## Datasets

All datasets are publicly available and are downloaded automatically or by the provided scripts:

| Dataset | Source | Used in |
|---------|--------|---------|
| Adult | UCI ML Repository | Tables 3–7, 9, 12, 15–22 |
| Bank-Marketing | UCI ML Repository | Tables 2, 10 |
| Telco-Customer-Churn | IBM Watson Analytics sample data | Tables 2, 10 |
| Secondary-Mushroom | UCI ML Repository | Tables 2, 10, 13 |
| TabReD (8 industry datasets) | [TabReD benchmark](https://github.com/yandex-research/tabred) | Table 11 |

```bash
# UCI / IBM datasets (Adult, Bank, Telco, Mushroom)
python download_adult.py

# TabReD datasets (requires Kaggle account; see https://github.com/yandex-research/tabred)
python download_tabred.py
```

## TabPFN Setup

Experiments use TabPFN v2 in two modes:

1. **Cloud client** (main comparison, Table 3): requires `tabpfn-client` and internet access; the API key is requested on first use.
2. **Local GPU** (all other tables): model weights are cached once, then inference is fully local. On first run, the `tabpfn` package downloads weights automatically (requires a one-time HuggingFace license acceptance for `Prior-Labs/*` repositories). Point the cache to a writable directory:

```bash
export TABPFN_MODEL_CACHE_DIR=/path/to/tabpfn_models
```

**Drift-Resilient TabPFN** (Table 9 only): clone the official third-party library and place it next to the `code/` directory:

```bash
git clone https://github.com/automl/Drift-Resilient_TabPFN.git ../Drift-Resilient_TabPFN-main
```

## Reproducing the Experiments

All scripts use 5 random seeds (42, 123, 456, 789, 2024) and write JSON result files to `../results/`.

### Table 3 — Main comparison (Adult, IID + feature-ordered, 11 methods)

Implemented in `context_shield_methods.py` (selection + evaluation functions). Run via the main comparison driver:

```bash
python context_shield_methods.py
```

### Tables 6–8 — Sensitivity analysis (K, context size)

```bash
python sensitivity_5seed_local.py
```

### Table 9 — Sub-additivity with Drift-Resilient TabPFN


## Notes for Reviewers

- **Runtime**: the full suite takes roughly 2–3 days on a single RTX Pro 2000 (16 GB). The TabReD benchmark (Table 11) and the TTA comparison (Table 16) dominate the cost; individual datasets can be run selectively as shown above.
- **Cloud vs local**: only Table 3 requires the TabPFN cloud client. An equivalence check on the Adult configuration showed differences ≤ 0.01 pp between the two backends.
- **Reproducibility**: every script seeds all random operations (`numpy`, `sklearn`, `torch`); rerunning with the same seeds reproduces the reported mean ± std within float32 precision.
- **JSON output**: each script writes its own result file to `../results/`; the file names match the table numbers (e.g., `tabred_benchmark_results.json` → Table 11).
